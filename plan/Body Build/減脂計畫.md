減脂的 config（SSOT）。`health-log` skill（由 `/daily` 內部呼叫）讀這裡的 frontmatter 做判斷，數字、課表、動作改這裡不改 skill：`schedule` 是週課表（index 0 = 週一），`run_workout` / `strength_workout` 是每日 health 檔「今日」區與 daily 看板顯示的動作內容。
- [[餐點速查]]
- [[health.base]]

臨時改課表（例如旅行週）可加：
```yaml
override_from: YYYY-MM-DD
override_to: YYYY-MM-DD
override_schedule: [strength_lower, rest, strength_full, rest, rest, rest, rest]
override_workouts:
  strength_lower: 深蹲 20×3・臀橋 20×3
  strength_full: 伏地挺身 10×3・棒式 45 秒×2
```

## 目標
- start_weight → goal_checkpoint_kg → goal_kg，每週 -0.3～0.5 kg
- checkpoint 到了先看腰圍、外觀、跑步表現，再決定是否往下
- 先跑 `baseline_weeks` 週 baseline，期間不因單日數字改計畫

## 飲食
- kcal_min～kcal_max/day 起點，蛋白質 protein_min～protein_max g/day
- 固定餐（午餐 / 早餐）寫在 [[餐點速查]] 的「固定餐」，方便「跟平常一樣」直接套
- 優先減：含糖飲料、零食、宵夜、不知不覺吃進去的高熱量

## 運動
- 跑步 × run_per_week / 週，不刻意加速加量
- 徒手阻力 × strength_per_week / 週，每次 20～25 分，目的是減脂期保肌
- 紀錄只記三態 done / partial / skipped，不逐動作記

## 量測與判斷
- 每天早上：起床 → 上廁所 → 未吃喝 → 量體重，兩位小數
- 只看 7 日平均，不看單日
- 每週落在 weekly_loss_min～weekly_loss_max → 不改
- 連續 2～3 週 7 日均幾乎沒降 → 減 adjust_kcal_min～adjust_kcal_max kcal/day
- 每週掉超過 weekly_loss_alert 且餓、疲勞、跑沒力 → 吃回一些

## 觀察項目
- 腸胃、腰圍、睡眠：有提到就記進 health.md 備註，沒提到不問

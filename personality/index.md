# 關於使用者 — 個性 / 價值觀 Wiki

這是 Claude 對使用者的認知檔案。**這是給 Claude 用的，不是使用者會手動打開或呼叫的東西**——當 Claude 要給個人化建議、或要新增關於使用者的內容時，由 Claude 自己載入 / 維護（透過 `about-me` skill）。目的有三：
1. Claude 在需要時快速了解使用者的個性與取向（一次 batch-load）。
2. Claude 隨著新的觀察更新這份檔案。
3. 對使用者主動提出的問題，給更個人化的建議。

> 語氣原則：不無條件奉承。建議要直接、對等、可被反駁。

## 如何維護這份檔案（給 Claude）

當在 `daily/YYYY/YYYY-MM-DD/journal.md`、daily entry、或對話中收到關於使用者的新個人想法時：

1. **判斷分類** — 對應上面目錄的某一頁；若都不合適，可在 `topics/` 新增一頁並更新本目錄表格。
2. **更新而非堆疊** — 先看該頁是否已涵蓋，優先修訂既有條目，避免重複。觀點若被推翻，直接改寫並在來源註明。
3. **一定要附來源** — 在該頁「來源」區用 wikilink 標明是哪一天的 journal（例 `[[daily/2026/2026-06-12/journal|journal 2026-06-12]]`）或哪個 reference dump。這是這份檔案可信度的根據。
4. **更新 frontmatter 的 `updated` 日期。**
5. **保持客觀** — 寫觀察到的事實與模式，不寫恭維。
6. **不要把分析過程講給他聽** — 直接更新檔案就好，他不需要看你怎麼推導出這些認知。

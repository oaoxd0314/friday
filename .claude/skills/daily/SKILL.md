# Daily（每日紀錄入口）

一個 session 記完一天的所有事。這個 skill 只做三件事：**開場看板、分流、收尾**。不自己算熱量、不自己寫日記、不自己組路徑，全部交給模組。

## 模組（用 Skill tool 載入，各自負責一塊，改邏輯只改該模組）

| 模組 | 負責 | 我怎麼用它 |
|---|---|---|
| `daily-note` | 日期（04:00 規則）、`daily/<YYYY>/<YYYY-MM-DD>/` 路徑、entry 檔（模板建立、habit 勾選、本日待辦、embed 位置）、Obsidian daily-notes 設定 | 開場先載入；所有 entry 檔的讀寫都走它 |
| `health-log` | `health.md`：體重 / 飲食 / 訓練 / 備註，frontmatter 重算，「今日」摘要區 | 身體類訊息全部轉給它，立刻處理 |
| `journal` | `journal.md`：靜默收集 → 「結束日記」整理成第一人稱日記 → 收縮建議 → 更新個性 wiki | 想法類訊息全部轉給它 |
| `about-me` | `personality/` 個性 wiki | journal 收尾時由它自己載入，我不直接碰 |

模組 SKILL.md 開頭都有「若使用者直接呼叫，改走 `daily`」的導向，所以他打 `/journal` 或 `/health-log` 也會回到這裡。

## 開場（每次進入都做，不管今天第幾次）

1. 載入 `daily-note`，取 `today`、`day_dir`，`ensure_entry()`，`ensure_health_embed()`，`ensure_review_embed(today)`。
2. 載入 `health-log`，跑它的「前置」：讀 config、確保 `health.md` 存在（骨架含今日課表與動作）。
3. 讀 `journal.md`（若存在）只為了知道今天已有幾段；不摘要內容。
4. 用 `daily-note.list_open()` 拿 entry 未完成項目。
5. 印看板，格式固定、不超過 7 行：

```
📅 2026-09-18（五）Day 6
🏋️ 五 💪 徒手：未記錄 → 深蹲 15–20×3・伏地挺身 8–15×3・…
🍱 ~1150 kcal / ~50 g（1/3 餐）｜體重 X，7 日均 Y
☑️ 未完成 4：冥想 / 讀書 / 側專案 / 運動
✍️ 日記：尚無（或：已有 1 段 21:30）
📌 Yesterday Review：有（或：無）
直接丟東西進來。「結束日記」收尾。
```

看板的每一行都來自檔案（health.md 的「今日」區、entry 的 checkbox、前一天 journal 是否有 `## review`），不是憑記憶。

## 分流（每則訊息）

一則訊息可能同時含多種，全部處理，順序：身體 → 待辦 → 想法。

- **身體**（體重數字、餐點、照片、標示、跑步、徒手、睡眠、腸胃、腰圍）→ `health-log` 立刻 upsert，**回它給的那一行**（例 `午餐 ~400 kcal / ~35 g，今日累計 ~820 / ~55（2/3 餐）`）。
- **待辦**（「加待辦 X」「今天要做 X」「X 做完了」「冥想完了」）→ `daily-note.add_todo / check_todo / mark_habit`，回一行 `已加：X` 或 `已勾：X`。
- **想法 / 心情 / 事件 / 反省** → `journal` 靜默收集，**只回 `#####`**。
- **混合**：先處理身體與待辦，回那一行；想法部分靜默收集，不再另回 `#####`。
- **提問**（「今天練什麼」「吃多少了」「還剩什麼沒做」）→ 讀檔回一行，不算日記素材。
- **判斷不了** → 當想法收集。不追問。真的需要問（例：「跟平常一樣」但預設餐待補）只問一句。
- **「暫停」** → 全部停止記錄，只等待；**「繼續」** 恢復。暫停期間收到的內容不記。

## 收尾（「結束日記」「結束」「今天到這」）

1. 有收集到想法 → 執行 `journal` 的「整理輸出」與「收縮想法、給建議」（含 about-me 建議、**`## review` 落到隔天 entry**、個性 wiki 更新）。對話裡的建議只是副本，正本在 journal 的 `## review`，隔天看板會提到它。
2. 沒有想法素材 → 跳過日記，不要硬寫。
3. 最後一行永遠是 `health-log` 的今日總結：`今日 ~2515 kcal / ~100 g（2/3 餐）｜💪 skipped｜體重 X`。
4. 收尾後 session 結束；同一天再進來就是重新開場，一切以檔案為準。

## 原則

- 狀態全在 `daily/<YYYY>/<YYYY-MM-DD>/` 三個檔，不依賴對話記憶；每個項目處理完立刻寫檔。
- 看板與回覆都短。白天不說教、不評論吃得好不好；唯一的建議時機是 `health-log` 體重規則與 `journal` 收尾。
- 全程繁體中文，不奉承，不說「你說的對」。
